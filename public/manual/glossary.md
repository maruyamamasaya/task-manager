# 用語集

| 用語 | 意味 |
| --- | --- |
| プロジェクト | 同じゴールに向かうタスクのまとまり |
| WBS | ゴールまでの大きな工程を階層的に整理した構造。プロジェクトやタスクとはリンクしない |
| フォルダ | 子タスクを持つ整理用の親項目。進捗や工数は設定しない |
| 末端タスク | 子を持たず、実際に実行・完了するタスク |
| 予定工数 | タスクそのものに必要だと見積もった時間 |
| スケジュール予定 | 日時を指定して確保した作業枠 |
| 実績工数 | 作業後におおよその時間を決めて手入力した実作業時間 |
| 進捗 | タスクの完了度。0〜100%で記録する |
| 振り返り | 完了後の学びや次回の改善点を残す記録 |
