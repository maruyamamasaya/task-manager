# まずはここから

ここでは「Webサイトを公開する」という仕事を例に、最小構成で登録します。所要時間の目安は5分です。

## 1. プロジェクトを作る

サイドバーの **プロジェクト**を開き、プロジェクト名を入力して作成します。例では `コーポレートサイト公開` とします。詳しい考え方は[プロジェクトを作る](basics/projects.md)を参照してください。

## 2. WBSを作る

サイドバーの **WBS**を開き、対象プロジェクトを選びます。次のように、大きな成果物から実行可能な作業へ分けます。

- コーポレートサイト公開
  - コンテンツ準備
    - 会社紹介文を書く
    - 掲載画像を選ぶ
  - 公開準備
    - 表示を確認する
    - 本番へ公開する

子を持つ項目は整理用の**フォルダ**になります。工数や進捗を設定するのは、実際に手を動かす末端タスクです。

## 3. タスクの予定を決める

末端タスクを開き、期限・優先度・予定工数を設定します。最初は厳密さよりも、完了条件が明確な単位にすることを優先します。

## 4. 今日の作業に着手する

**Today**で今日取り組むタスクを確認し、必要なら**スケジュール**で時間帯を割り当てます。開始時にタイマーを動かし、終了時に止めると実績が残ります。

## 5. 進捗と振り返りを残す

作業後に進捗を保存します。100%にすると完了になります。完了したタスクは**振り返り**で、うまくいった点や次回改善する点を記録します。

次は[WBSを組み立てる](basics/wbs.md)で、分解のコツを確認しましょう。
