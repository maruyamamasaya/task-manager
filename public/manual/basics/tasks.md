# タスクを実行・更新する

**タスク**画面では、WBSで作った末端タスクの詳細を編集し、作業の状態を更新します。

## 実行前に設定する項目

- **期限**: その日までに終える必要がある日
- **優先度**: 同じ期限のタスクで着手順を決める目安
- **予定工数**: 実際に手を動かす時間の見積り
- **進捗**: 0〜100%。保存時に状態も連動する

進捗は 0% が未着手、1〜99% が進行中、100% が完了です。スライダーを動かした後は、明示的に保存してください。

## 作業時間を記録する

作業開始時にタイマーを開始し、終了時に停止します。後から記録する場合は、実績時間を分単位で追加できます。予定工数と実績時間は別の値なので、作業後に見積りとの差を確認できます。

## タスクを完了する

1. 成果物や完了条件を確認する
2. 進捗を100%にして保存する
3. 予定と実績の差を確認する
4. 必要なら[振り返り](../workflow/reflection.md)を入力する
