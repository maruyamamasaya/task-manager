# タスクを実行・更新する

**タスク**画面では、実際に手を動かす作業を実務レベルに切り分けて登録し、作業の状態を更新します。

> **タスクとWBSの項目はリンクしていません。** WBSには日ごとに進める大きな工程を置き、タスクには、その工程を進めるための具体的な作業を別途登録してください。

## 実行前に設定する項目

- **期限**: その日までに終える必要がある日
- **優先度**: 同じ期限のタスクで着手順を決める目安
- **予定工数**: 実際に手を動かす時間の見積り
- **進捗**: 0〜100%。保存時に状態も連動する

進捗は 0% が未着手、1〜99% が進行中、100% が完了です。スライダーを動かした後は、明示的に保存してください。

## 作業時間を記録する

> **現在、タイマー機能は停止しています。** 作業時間は厳密に計測する必要はありません。作業後におおよその時間を自分で決め、実績時間として分単位で手入力してください。

予定工数と実績時間は別の値なので、手入力した実績を使って見積りとの差を確認できます。

## タスクを完了する

1. 成果物や完了条件を確認する
2. 進捗を100%にして保存する
3. 予定と実績の差を確認する
4. 必要なら[振り返り](../workflow/reflection.md)を入力する
