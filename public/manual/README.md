# Taskflow 使い方マニュアル

Taskflow は、仕事を **プロジェクト → WBS → 実行するタスク** の順に整理し、予定・実績・進捗・振り返りをひとつにつなげるツールです。

## このマニュアルでできるようになること

- プロジェクトを作り、ゴールや期間を整理する
- WBSで作業を最大3階層に分解する
- 今日のタスクを選び、予定工数とスケジュールを決める
- 作業時間と進捗を記録し、完了後に振り返る

初めて使う場合は、[まずはここから](getting-started.md) を読みながら、ひとつの小さなプロジェクトを登録してください。

> このマニュアルは Markdown ファイルを Docsify でそのまま表示しています。左側の目次または検索から必要なページへ移動できます。

## 最短の流れ

1. **プロジェクト**で仕事のまとまりを作る
2. **WBS**で成果物から具体的な作業へ分解する
3. 末端のタスクに予定工数・期限・優先度を設定する
4. **Today / スケジュール**で今日実行する時間を決める
5. タイマーまたは手入力で実績を残し、進捗を更新する
6. 完了したら**振り返り**を記録する
