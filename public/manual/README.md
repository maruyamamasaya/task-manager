# Taskflow 使い方マニュアル

Taskflow は、仕事を **プロジェクト・WBS・実行するタスク** に整理し、予定・実績・進捗・振り返りを管理するツールです。

> **WBSは、プロジェクト画面やタスク画面とは独立して管理します。** プロジェクト画面で作ったプロジェクトと、WBS画面のプロジェクトはリンクしていないため、対応が分かるように名前を合わせて運用してください。また、WBSの項目とタスクもリンクしていません。WBSには日ごとに進める大きな工程を置き、タスクには実務レベルの具体的な作業を登録します。

## このマニュアルでできるようになること

- プロジェクトを作り、ゴールや期間を整理する
- WBSで大きな工程を最大3階層に整理する
- 今日のタスクを選び、予定工数とスケジュールを決める
- 作業時間と進捗を記録し、完了後に振り返る

初めて使う場合は、[まずはここから](getting-started.md) を読みながら、ひとつの小さなプロジェクトを登録してください。

> このマニュアルは Markdown ファイルを Docsify でそのまま表示しています。左側の目次または検索から必要なページへ移動できます。

## 最短の流れ

1. **プロジェクト**で仕事のまとまりを作る
2. **WBS**で日ごとに進める大きな工程を整理する
3. **タスク**に実務レベルの作業を登録し、予定工数・期限・優先度を設定する
4. **Today / スケジュール**で今日実行する時間を決める
5. 作業後におおよその実績時間を手入力し、進捗を更新する
6. 完了したら**振り返り**を記録する

> **現在、タイマー機能は停止しています。** 実績時間は作業後におおよその時間を決め、手入力してください。
